As artes de Caixa de Ronrons possuem cópias WebP com largura de 1000 px e qualidade 86. Os originais permanecem nos projetos dos jogos.

A cápsula de Normal Dev Guy foi substituída a pedido do usuário em 15/10/2026 pela imagem efetivamente exibida na [Steam](https://store.steampowered.com/app/4506350/). Origem: `https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/4506350/86df2079dc93429ede3c6a0086a48d0c5894de5d/header.jpg?t=1791929803`. A cópia JPEG tem 460 × 215 px e foi preservada sem reedição. O layout usa `object-fit: contain` com fundo escuro para manter o título completo na inicial e no catálogo.

`share.png` é a arte de compartilhamento de 1200 × 630 px criada para o estúdio. Nenhum recurso visual é carregado de servidor de terceiros. Não há fontes externas.

`public/assets/alerta-terra.webp` é uma cópia otimizada de `E:/Godot Projetos/meus projetos/alerta-terra/assets/alien/art/launch/boot_splash.png`, de 720 × 720 px, para o catálogo Android. A arte original não foi modificada. A descrição do jogo veio do README e do gameplay de defesa/invasão do próprio projeto. Não foi inventado um link de loja nem uma edição PC para divulgação.

Os direitos e as licenças dos materiais dos jogos permanecem com seus respectivos titulares; esta cópia não cria uma licença adicional.
